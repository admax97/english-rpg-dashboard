
# English RPG System

Интерактивный mini-app для изучения английского языка.

Функции:
- Daily lesson tracker
- XP и Level system
- Achievements
- Streak tracking
- Notes
- LocalStorage save
- Mobile friendly UI

## Установка

### 1. Установить Node.js
https://nodejs.org/

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить локально

```bash
npm run dev
```

### 4. Production build

```bash
npm run build
```

## Deploy на Netlify

### Вариант 1 - Через GitHub

1. Загрузи проект в GitHub
2. Зайди в Netlify
3. New Site From Git
4. Выбери репозиторий
5. Build command:
```bash
npm run build
```

6. Publish directory:
```bash
dist
```

### Вариант 2 - Drag & Drop

После:
```bash
npm run build
```

Загрузи папку dist в Netlify.
